# 02 — CEFR Scope A1–B2 (topic list)

Aligned with British Council / EAQUALS Core Inventory + ESL-Tests topic map. 12 topics per level, 48 total. Order inside a level = teaching order.

## A1 — Foundations (12)

1. `a1-01-verb-to-be` — am/is/are, negatives, questions, short answers
2. `a1-02-present-simple` — do/does, 3rd -s, negatives, questions, frequency adverbs
3. `a1-03-present-continuous` — now-actions, spelling (-ing), vs present simple (intro)
4. `a1-04-past-simple-be` — was/were, there was/were
5. `a1-05-articles` — a/an/the/zero, first-mention rule
6. `a1-06-nouns-plurals` — regular/irregular plurals, this/that/these/those
7. `a1-07-pronouns` — subject/object (I/me), possessive adjectives (my/your)
8. `a1-08-possessives` — 's/s', possessive pronouns (mine/yours), have got
9. `a1-09-prepositions` — place (in/on/at) + time (in/on/at), basic movement
10. `a1-10-modals-can` — can/can't/could (ability, permission, request)
11. `a1-11-imperatives` — do/don't, let's, like + -ing (love/hate/like)
12. `a1-12-there-is-are-connectors` — there is/are, how much/many, and/but/or/so/because

## A2 — Past + Comparison + Future (12)

1. `a2-01-past-simple-regular` — -ed spelling/pronunciation, ago/yesterday/last
2. `a2-02-past-simple-irregular` — top-60 irregulars, negatives/questions (did)
3. `a2-03-past-continuous` — was/were + -ing, interrupted actions (when/while)
4. `a2-04-going-to-will` — plans (going to) vs predictions/promises (will)
5. `a2-05-comparatives-superlatives` — -er/-est, more/most, than/the, as…as
6. `a2-06-countable-uncountable` — some/any/much/many/a lot of, how much/many
7. `a2-07-modals-a2` — could/should/may/might/must/have to (obligation/advice)
8. `a2-08-zero-first-conditional` — zero (facts) + first (if + present, will)
9. `a2-09-gerund-basics` — verb + -ing/infinitive: like/want/would like/need
10. `a2-10-adverbs-frequency-manner` — always→never, -ly formation, word order
11. `a2-11-relative-basic` — who/which/that defining clauses
12. `a2-12-reported-basic` — say/tell statements, backshift intro, time changes

## B1 — Independence (12)

1. `b1-01-present-perfect` — have/has + V3, ever/never/just/already/yet, for/since
2. `b1-02-present-perfect-continuous` — have been + -ing, how long, vs simple
3. `b1-03-past-perfect` — had + V3, before/after/by the time, vs past simple
4. `b1-04-second-conditional` — if + past, would/could/might (unreal present)
5. `b1-05-third-conditional` — if + past perfect, would have + V3 (past regret)
6. `b1-06-passive-basic` — be + V3 (present/past simple), by-agent, -by omission
7. `b1-07-reported-speech` — statements/questions/commands, say vs tell, backshift full
8. `b1-08-modal-deduction` — must/can't/might/may (deduction), must/have to (obligation)
9. `b1-09-used-to-would` — past habits, used to + V vs be/get used to + -ing
10. `b1-10-relative-defining` — defining with whose/where/when, omitting object pronouns
11. `b1-11-gerund-infinitive` — remember/stop/try + -ing vs to (meaning change)
12. `b1-12-question-tags-linkers` — tags (isn't it?), although/despite/however/because of

## B2 — Complexity (12)

1. `b2-01-mixed-conditionals` — past condition → present result + reverse
2. `b2-02-wish-if-only` — wish + past (present regret), + past perfect (past regret)
3. `b2-03-passive-advanced` — continuous/perfect/modal passives, have sth done intro
4. `b2-04-reported-range` — full range: suggestions/offers/promises, reporting verbs
5. `b2-05-participle-clauses` — -ing/-ed clauses (having finished, broken window)
6. `b2-06-causative` — have/get something done, make/let/help + bare infinitive
7. `b2-07-inversion` — never/rarely/not only…but also + inversion
8. `b2-08-cleft-emphasis` — it-clefts, what-clefts, fronting
9. `b2-09-subjunctive-basics` — suggest/demand/insist + (should) + V, it's time + past
10. `b2-10-reduced-relatives` — the man standing…, the book written…
11. `b2-11-advanced-conjunctions` — nevertheless/whereas/in spite of/despite + noun/-ing
12. `b2-12-narrative-tenses` — past simple/continuous/perfect selection in stories
