# A1-12 There is / are, much / many, connectors

## Goal
You can say what exists with there is/are, ask about quantity, and link ideas simply.

## Rule in 60 seconds
Varlık: tekil → **there is**, çoğul → **there are**. Geçmişi: there was/were.
Soru: `Is there...?` / `Are there...?` Olumsuz: there isn't / there aren't.
Sayılabilen çoğulla many / How many; sayılamayanla much / How much.
Olumluda much/many yerine genelde a lot of (lots of).
Bağlaçlar: and (ekleme), but (zıtlık), or (seçim), so (sonuç), because (sebep).
because + cümle, because of + isim: ...because it rains / ...because of the rain.
so ile sonuç, because ile sebep başa da gelebilir: Because it rains, stay in.
or soruda seçenek sunar: `Tea or coffee?`
but cümle ortasında virgülle: `She is tired, but she is happy.`
and listede son öğeden önce: apples, bananas and grapes.
so + sıfat kalıbı: `so tired`, `so late` — sonuç cümlesi gelir.

## Forms

| Form | Pattern | Examples |
|------|---------|----------|
| + Singular | There is + a/an + singular | **There is** a bank here. |
| + Plural | There are + number/some + plural | **There are** two banks here. |
| − Negative | There isn't / aren't | **There isn't** any milk. / **There aren't** any eggs. |
| ? Question | Is/Are there ...? | **Is there** a toilet? / **Are there** any shops? |
| How much | How much + uncountable? | **How much** money have you got? |
| How many | How many + countable plural? | **How many** brothers have you got? |
| some / any | some (+), any (−/?) | I have **some** friends. / I don't have **any**. |
| a lot of | + both (mostly +) | She has **a lot of** books. |
| and / but / or | clause + conj + clause | I like tea **and** coffee. / Small **but** clean. |
| so / because | reason-result links | It rains, **so** stay in. / Stay in **because** it rains. |

some rica/teklifte soruda da olur: Would you like some tea?
any + tekil sayılamayan ya da çoğul sayılabilenle kullanılır.

## 3 classic traps

1. **is/are seçimi there'den SONRAKİ isme göre.**
   - ✗ There is many people. → ✓ **There are** many people.
   - ✗ There are a book. → ✓ **There is** a book.
   - Bakılacak yer there değil, arkadaki isimdir.
2. **much/many ayrımı.**
   - ✗ How much brothers? → ✓ **How many** brothers?
   - ✗ How many money? → ✓ **How much** money?
   - Test: çoğul yapabiliyorsan many, yapamıyorsan much.
3. **because + cümle, because of + isim.**
   - ✗ I stayed because the rain. → ✓ I stayed **because of** the rain.
   - ✗ I stayed because of it rains. → ✓ I stayed **because** it rains.
   - because'dan sonra özne + fiil şarttır.

## 10 example sentences

1. **There is** a cat in the garden. — Bahçede bir kedi var.
2. **There are** many shops here. — Burada çok dükkân var.
3. **There isn't** any coffee. — Hiç kahve yok.
4. **Are there** any questions? — Soru var mı?
5. **How many** students are there? — Kaç öğrenci var?
6. **How much** sugar do you want? — Ne kadar şeker istersin?
7. I like tea **and** my wife likes coffee. — Çayı severim ve eşim kahve sever.
8. It is small **but** comfortable. — Küçük ama rahat.
9. It is raining, **so** take an umbrella. — Yağmur yağıyor, o yüzden şemsiye al.
10. She stayed at home **because** she was ill. — Hasta olduğu için evde kaldı.

## Quick check

1. Fill in: ___ (There is / There are) a lot of people here.
<details><summary>Answer</summary><b>There are</b> a lot of people here. (people çoğul)</details>

2. Choose: How (much / many) water do you drink?
<details><summary>Answer</summary>How <b>much</b> water do you drink? (water sayılamaz)</details>

3. Correct: I stayed home because of it was cold.
<details><summary>Answer</summary>I stayed home <b>because</b> it was cold. (cümle → because)</details>
