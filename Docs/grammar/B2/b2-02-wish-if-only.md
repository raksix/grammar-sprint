# B2-02 Wish / If Only

## Goal

Express present and past regrets correctly with wish and if only.

After this lesson you can:

- Talk about present regrets with wish + past.
- Talk about past regrets with wish + past perfect.
- Strengthen emotion with if only.

## Rule in 60 seconds

Wish + past simple = şimdiki pişmanlık.

Wish + past perfect = geçmiş pişmanlık.

If only aynı kuralla daha güçlü duygu verir.

Kısaca: bir adım geriye git.

Kısa mantık:

- Şimdi → past simple.
- Geçmiş → past perfect.

## Forms

| Use | Pattern | Example |
|---|---|---|
| Present regret | wish + past simple | I wish I knew the answer. |
| Present regret | wish + past simple | I wish she were here now. |
| Past regret | wish + past perfect | I wish I had studied harder. |
| Past regret | wish + past perfect | I wish we hadn't sold the car. |
| If only present | If only + past simple | If only I had more time! |
| If only present | If only + past simple | If only he listened to me! |
| If only past | If only + past perfect | If only I'd left earlier! |
| If only past | If only + past perfect | If only they hadn't argued! |

Kısa Türkçe not: "I wish I am" denmez.

Kısa Türkçe not: Wish'ten sonra fiil bir geçmiş zamana kayar.

Not: Would daha çok şikâyet içindir: "I wish you would stop."

## 3 classic traps

1. TR: "I wish I have more money"
   DOĞRU: "I wish I had more money."
   Sebep: Wish sonrası present kullanılmaz.
2. TR: "I wish I would be rich" (kalıcı durumlar)
   DOĞRU: "I wish I were rich."
   Sebep: Would şikâyet/istek içindir, durum için değil.
3. TR: If only + would karıştırmak
   DOĞRU: "If only I had known."
   Sebep: Geçmiş pişmanlıkta would değil had + V3.

## 10 example sentences

1. I wish I spoke French.
   Keşke Fransızca konuşsam.
2. I wish she were here with us.
   Keşke o şimdi bizimle burada olsaydı.
3. I wish I had taken that offer.
   Keşke o teklifi kabul etseydim.
4. If only I had more free time!
   Keşke daha çok boş vaktim olsaydı!
5. If only we'd left ten minutes earlier!
   Keşke on dakika erken çıksaydık!
6. I wish you would stop shouting.
   Keşke bağırmayı kessen. (şikâyet)
7. I wish I hadn't eaten so much.
   Keşke bu kadar çok yemeseydim.
8. If only he knew the truth.
   Keşke gerçeği bilseydi.
9. I wish we lived closer to the sea.
   Keşke denize daha yakın otursaydık.
10. If only she hadn't missed the deadline!
    Keşke son tarihi kaçırmasaydı!

## Quick check

1. I wish I ___ (can) drive.
   Cevap: could. (Present regret → past form.)
2. I wish I ___ (not / say) that yesterday.
   Cevap: hadn't said. (Past regret → past perfect.)
3. "I wish I have a car" cümlesini düzelt.
   Cevap: I wish I had a car.
