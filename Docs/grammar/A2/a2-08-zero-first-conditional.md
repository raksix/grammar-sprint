# Zero and First Conditional

## Goal

- State facts with **zero conditional** and real future possibilities with **first conditional**.
- (TR: Genel gerçekler için zero, gerçekleşebilir gelecek için first conditional.)

## Rule in 60 seconds

- Zero: **If + present simple, present simple** — facts and habits: If you heat ice, it melts.
- First: **If + present simple, will + base verb** — real future: If it rains, we will stay home.
- The if-clause can come second (no comma): We will stay home if it rains.
- (TR: Zero'da iki taraf da geniş zaman. First'te if'ten sonra will yok — will sonuç cümlesinde.)

## Forms

| Type | If-clause | Main clause | Example |
|---|---|---|---|
| Zero | If + present simple | present simple | If you press this, it starts. |
| First | If + present simple | will + V | If you press this, it will break. |
| First negative | If + don't/doesn't + V | won't + V | If you don't hurry, you'll miss it. |
| Swapped order | Main clause + if-clause (no comma) | — | You'll miss it if you don't hurry. |

- Alternatives to will: can/may/imperative in the result (If you're hot, open the window).
- Unless = if not: Unless you hurry, you'll be late.
- (TR: unless = if … not. Emir cümlesi de sonuç olabilir: If you're tired, rest.)

## 3 classic traps

1. **will in the if-clause:** ❌ *If it will rain, we stay.* → ✅ *If it rains, we will stay.* (TR: if'ten sonra will gelmez.)
2. **Mixing the two:** ❌ *If water boils, it will become steam.* (fact) → ✅ *If water boils, it becomes steam.* (TR: Bilimsel gerçek → zero.)
3. **Comma with swapped order:** ❌ *We will stay home, if it rains.* → ✅ *We will stay home if it rains.* (TR: if ortadaysa virgül yok.)

## 10 example sentences

1. **If** you heat water, it boils. (Suyu ısıtırsan kaynar — gerçek.)
2. **If** it snows, classes stop. (Kar yağarsa dersler durur — genel kural.)
3. **If** it rains, we**'ll stay** home. (Yağmur yağarsa evde kalacağız.)
4. **If** you study, you**'ll pass**. (Çalışırsan geçersin.)
5. She**'ll be** angry **if** we are late. (Geç kalırsak kızar.)
6. **If** you don't hurry, you**'ll miss** the bus. (Acele etmezsen otobüsü kaçırırsın.)
7. **Unless** you call, I**'ll worry**. (Aramazsan endişelenirim.)
8. **If** you're hungry, eat something. (Açsan bir şey ye.)
9. **If** I see him, I**'ll tell** him. (Onu görürsem söylerim.)
10. Plants die **if** you don't water them. (Sulamazsan bitkiler ölür — zero.)

## Quick check

1. Fill in (zero): If ice ___ (melt), it becomes water.
2. Fill in (first): If she comes, I ___ (be) happy.
3. Correct the error: *If it will snow, we will cancel.*
4. Choose: "___ you mix red and blue, you get purple." (If / Will)
5. True or false: "We'll go out, if it stops." needs the comma.

<details>
<summary>Answers</summary>

1. melts
2. will be (’ll be)
3. If it snows, we will cancel.
4. If
5. False — "We'll go out if it stops."
