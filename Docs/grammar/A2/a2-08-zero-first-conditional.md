# Zero and First Conditional

## Goal


- **State** facts with **zero conditional** and real future possibilities with **first conditional**.
- **TR:** Genel gerçekler için zero, gerçekleşebilir gelecek için first conditional.

- **Success check:** say one fact (zero) and one real plan (first).


## Rule in 60 seconds


- **Zero:** **If + present simple, present simple** — facts and habits: If you heat ice, it melts.
- **First:** **If + present simple, will + base verb** — real future: If it rains, we will stay home.
- **The if-clause can come second (no comma):** We will stay home if it rains.
- **TR:** Zero'da iki taraf da geniş zaman. First'te if'ten sonra will yok — will sonuç cümlesinde.

- **Comma rule:** if-clause first → comma; if-clause middle → no comma.

- **No will after if:** If it rains — never If it will rain.

- **Tense map:** zero = present + present; first = present + will.


## Forms


| Type | If-clause | Main clause | Example |
|---|---|---|---|
| Zero | If + present simple | present simple | If you press this, it starts. |
| First | If + present simple | will + V | If you press this, it will break. |
| First negative | If + don't/doesn't + V | won't + V | If you don't hurry, you'll miss it. |
| Swapped order | Main clause + if-clause (no comma) | — | You'll miss it if you don't hurry. |

- **Alternatives to will:** can/may/imperative in the result (If you're hot, open the window).
- **Unless = if not:** Unless you hurry, you'll be late.
- **TR:** unless = if … not. Emir cümlesi de sonuç olabilir: If you're tired, rest.

- **Order swap:** We'll stay if it rains — same meaning, no comma.

- **Result options:** will, can or an order — If you're hot, open the window.

- **Zero test:** a scientific fact takes present on both sides.


## 3 classic traps


- **will in the if-clause:** ❌ *If it will rain, we stay.* → ✅ *If it rains, we will stay.* (TR: if'ten sonra will gelmez.)
- **Mixing the two:** ❌ *If water boils, it will become steam.* (fact) → ✅ *If water boils, it becomes steam.* (TR: Bilimsel gerçek → zero.)
- **Comma with swapped order:** ❌ *We will stay home, if it rains.* → ✅ *We will stay home if it rains.* (TR: if ortadaysa virgül yok.)


## 10 example sentences


- **If you heat water, it boils.** — Suyu ısıtırsan kaynar — gerçek.
- **If it snows, classes stop.** — Kar yağarsa dersler durur — genel kural.
- **If it rains, we'll stay home.** — Yağmur yağarsa evde kalacağız.
- **If you study, you'll pass.** — Çalışırsan geçersin.
- **She'll be angry if we are late.** — Geç kalırsak kızar.
- **If you don't hurry, you'll miss the bus.** — Acele etmezsen otobüsü kaçırırsın.
- **Unless you call, I'll worry.** — Aramazsan endişelenirim.
- **If you're hungry, eat something.** — Açsan bir şey ye.
- **If I see him, I'll tell him.** — Onu görürsem söylerim.
- **Plants die if you don't water them.** — Sulamazsan bitkiler ölür — zero.


## Quick check


- **Q1:** Fill in (zero): If ice ___ (melt), it becomes water.
- **Q2:** Fill in (first): If she comes, I ___ (be) happy.
- **Q3:** Correct the error: *If it will snow, we will cancel.*
- **Q4:** Choose: "___ you mix red and blue, you get purple." (If / Will)
- **Q5:** True or false: "We'll go out, if it stops." needs the comma.

- **Q6:** Fill in (first): If he hurries, he ___ (catch) the bus.
<details>
<summary>Answers</summary>

- **A1:** melts
- **A2:** will be (’ll be)
- **A3:** If it snows, we will cancel.
- **A4:** If
- **A5:** False — "We'll go out if it stops."

- **A6:** will catch ('ll catch).
</details>
