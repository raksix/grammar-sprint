# B1-09 Used To and Would

## Goal

- Describe past habits with used to + V and would + V.
- Never confuse used to (past habit) with be/get used to + -ing (accustomed).
- TR: Eski aliskanliklari anlatmak ve "alisik olmak"tan ayirmak.

## Rule in 60 seconds

- Past habit: **used to + base verb** (states and actions), **would + base verb** (actions only).
- Accustomed: **be/get used to + noun/-ing** (I am used to cold weather).
- TR: used to + yalın fiil = eskiden yapardim; used to + -ing = alisigim.

## Forms

| Pattern | Example | Use |
|---|---|---|
| used to + V | I used to play chess. | past habit (no longer true) |
| would + V | We would visit grandma. | past repeated action |
| didn't use to + V | I didn't use to like tea. | negative (no -d on use) |
| Did ... use to + V? | Did you use to swim? | question (no -d on use) |
| be used to + -ing | I am used to waking early. | accustomed now |
| get used to + -ing | She got used to the noise. | became accustomed |

- would needs a time frame and action verb: "When I was a child, we would go fishing."
- TR: would durum fiilleriyle (be, have, know) kullanilmaz.
- Pronunciation: used to = /juːstə/.

```text
I USED TO smoke. (eskiden, artik degil)
We WOULD play outside every evening. (cocukken, tekrarlanan eylem)
I AM USED TO working nights. (alisigim — -ing'e dikkat)
```

## 3 classic traps

### 1. Did + used (with -d)

- Wrong: Did you used to play?
- Right: Did you use to play?
- TR: Did gelince used yalınlasir: use to.

### 2. Would with state verbs

- Wrong: I would be shy as a child.
- Right: I used to be shy as a child.
- TR: be, know, like, have ile used to kullan, would degil.

### 3. used to + -ing mix-up

- Wrong: I used to waking up early. (means habit, wrong form)
- I am used to waking up early. (I am accustomed — correct with be)
- TR: -ing varsa onunde be/get olmali.

## 10 example sentences

1. I used to play football every weekend. — Eskiden her hafta sonu futbol oynardim.
2. She didn't use to like coffee. — Eskiden kahve sevmezdi.
3. Did you use to live in Istanbul? — Eskiden Istanbul'da mi yasiyordun?
4. When we were kids, we would go fishing. — Cocukken baliga giderdik.
5. He used to be very shy. — Eskiden cok utangacti.
6. I am used to getting up early. — Erken kalkmaya alisigim.
7. She got used to working night shifts. — Gece vardiyasina alisti.
8. They would visit us every summer. — Her yaz bizi ziyaret ederlerdi.
9. It is hard, but you'll get used to it. — Zor ama buna alisacaksin.
10. We used to have a dog called Max. — Max adinda bir kopegimiz vardi.

## Quick check

1. I ___ to play chess. (used/use) → used.
2. Fix: "Did you used to swim?" → Did you use to swim?
3. As a child she ___ be afraid of dogs. (would/used to) → used to.
4. I am used to ___ (work) late. → working.
5. They ___ visit us every year. (would/used to — both?) → both ok (action).
6. She got used to ___ (drive) in snow. → driving.
7. Fix: "I used to waking early." → I am used to waking early. / I used to wake...
8. Negative: I ___ use to eat meat. → didn't.
