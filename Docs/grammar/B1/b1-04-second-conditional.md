# B1-04 Second Conditional

## Goal

- **Not:** Talk about unreal present/future situations with if + past simple, would + V.
- **Not:** Distinguish real possibility (first) from imagination (second).
- **TR:** Hayali, gercek disi durumlari ve sonuclarini anlatmak.


## Rule in 60 seconds

- **Form:** **If + past simple, would/could/might + base verb**.
- **Not:** Past here is not past time — it marks unreality.
- **TR:** If'li kisimda past, sonuc kisminda would kullan.


## Forms

| If-clause | Main clause |
|---|---|
| If I had more money, | I would travel more. |
| If she studied harder, | she could pass. |
| If we lived closer, | we might meet often. |

- **`were` for all subjects in formal style:** If I were you, I would stay.
- **TR:** If I was yerine If I were daha dogru kabul edilir.
- **Modal options:** would (certain result), could (ability), might (possibility).
- **Word order:** Would you come if I invited you? (= If I invited you, would you come?)
- **Kalıp:** If I were you, I would... = tavsiye kalıbı.

- **Örnek:** `If + PAST, would + V`
- **Örnek:** `If I WON the lottery, I WOULD buy a house.`
- **Örnek:** `If I WERE you, I WOULD apologise.`
- **Örnek:** `What WOULD you do if you SAW a ghost?`


## 3 classic traps

- **Tuzak 1 — Would in both clauses:** ❌ `If I would have time, I would help.` → ✅ `If I had time, I would help.`
- **TR:** If'li kisma would gelmez.

- **Tuzak 2 — Using present simple for unreal situations:** ❌ `If I am rich, I would travel.` → ✅ `If I were rich, I would travel.`
- **TR:** Hayalse if'ten sonra past kullan.

- **Tuzak 3 — Confusing first and second conditional:** ❌ `If it rains, we would stay.` → ✅ `If it rains, we will stay. / If it rained, we would stay.`
- **İpucu:** Gerçek ihtimal will, hayal would.
- **TR:** Gercek ihtimal will, hayal would.


## 10 example sentences

- **If I had more time, I would learn Spanish.** — Daha cok vaktim olsa Ispanyolca ogrenirdim.
- **If I were you, I would take the job.** — Yerinde olsam isi kabul ederdim.
- **What would you do if you lost your phone?.** — Telefonunu kaybetsen ne yapardin?
- **If she knew the answer, she would tell us.** — Cevabi bilse bize soylerdi.
- **I would travel the world if I were rich.** — Zengin olsam dunyayi gezerdim.
- **If they invited me, I would definitely go.** — Davet etseler kesinlikle giderdim.
- **He could help us if he came earlier.** — Erken gelse bize yardim edebilirdi.
- **If we lived by the sea, we might swim every day.** — Deniz kenarinda yasasak her gun yuzebilirdik.
- **Would you forgive me if I apologised?.** — Ozur dilesem beni affeder misin?
- **If it snowed in June, everyone would be shocked.** — Haziranda kar yagsa herkes sasirirdi.


## Quick check

- **Soru 1:** If I ___ (have) a car, I would drive to work. → had.
- **Soru 2:** If I ___ you, I would study more. (was/were) → were.
- **Soru 3:** Fix: "If I would know, I would tell." → If I knew, I would tell.
- **Soru 4:** What ___ you do if you ___ (win) money? → would / won.
- **Soru 5:** First or second? "If it rains, we'll cancel." → first (real).
- **Soru 6:** If she ___ (come), she could help. → came.
- **Soru 7:** ___ you go if he invited you? → Would.
- **Soru 8:** If we lived closer, we ___ (meet) more. → would meet.
