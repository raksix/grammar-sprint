# B1-04 Second Conditional

## Goal

- Talk about unreal present/future situations with if + past simple, would + V.
- Distinguish real possibility (first) from imagination (second).
- TR: Hayali, gercek disi durumlari ve sonuclarini anlatmak.

## Rule in 60 seconds

- Form: **If + past simple, would/could/might + base verb**.
- Past here is not past time — it marks unreality.
- TR: If'li kisimda past, sonuc kisminda would kullan.

## Forms

| If-clause | Main clause |
|---|---|
| If I had more money, | I would travel more. |
| If she studied harder, | she could pass. |
| If we lived closer, | we might meet often. |

- `were` for all subjects in formal style: If I were you, I would stay.
- TR: If I was yerine If I were daha dogru kabul edilir.
- Modal options: would (certain result), could (ability), might (possibility).
- Word order: Would you come if I invited you? (= If I invited you, would you come?)

```text
If + PAST, would + V
If I WON the lottery, I WOULD buy a house.
If I WERE you, I WOULD apologise.
What WOULD you do if you SAW a ghost?
```

## 3 classic traps

### 1. Would in both clauses

- Wrong: If I would have time, I would help.
- Right: If I had time, I would help.
- TR: If'li kisma would gelmez.

### 2. Using present simple for unreal situations

- Wrong: If I am rich, I would travel.
- Right: If I were rich, I would travel.
- TR: Hayalse if'ten sonra past kullan.

### 3. Confusing first and second conditional

- First (possible): If it rains, we will stay home.
- Second (imaginary): If it rained every day, we would move.
- TR: Gercek ihtimal will, hayal would.

## 10 example sentences

1. If I had more time, I would learn Spanish. — Daha cok vaktim olsa Ispanyolca ogrenirdim.
2. If I were you, I would take the job. — Yerinde olsam isi kabul ederdim.
3. What would you do if you lost your phone? — Telefonunu kaybetsen ne yapardin?
4. If she knew the answer, she would tell us. — Cevabi bilse bize soylerdi.
5. I would travel the world if I were rich. — Zengin olsam dunyayi gezerdim.
6. If they invited me, I would definitely go. — Davet etseler kesinlikle giderdim.
7. He could help us if he came earlier. — Erken gelse bize yardim edebilirdi.
8. If we lived by the sea, we might swim every day. — Deniz kenarinda yasasak her gun yuzebilirdik.
9. Would you forgive me if I apologised? — Ozur dilesem beni affeder misin?
10. If it snowed in June, everyone would be shocked. — Haziranda kar yagsa herkes sasirirdi.

## Quick check

1. If I ___ (have) a car, I would drive to work. → had.
2. If I ___ you, I would study more. (was/were) → were.
3. Fix: "If I would know, I would tell." → If I knew, I would tell.
4. What ___ you do if you ___ (win) money? → would / won.
5. First or second? "If it rains, we'll cancel." → first (real).
6. If she ___ (come), she could help. → came.
7. ___ you go if he invited you? → Would.
8. If we lived closer, we ___ (meet) more. → would meet.
