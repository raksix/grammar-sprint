# B1-05 Third Conditional

## Goal

- Talk about past regrets and imaginary past results with if + past perfect, would have + V3.
- Contrast second (present imagination) vs third (past regret) conditionals.
- TR: Gecmiste olmamis seyler icin pismanlik ve hayal kurmak.

## Rule in 60 seconds

- Form: **If + past perfect, would/could/might have + V3**.
- Both parts refer to the past; neither happened.
- TR: If'li kisimda had + V3, sonuc kisminda would have + V3.

## Forms

| If-clause | Main clause |
|---|---|
| If I had studied harder, | I would have passed. |
| If she had left earlier, | she wouldn't have missed the bus. |
| If we had known, | we could have helped. |

- Contractions: I'd have = I would have; hadn't = had not.
- TR: If I'd known = Bilseydim.
- Modal shades: would have (certain), could have (ability), might have (possibility).
- Inversion (formal): Had I known, I would have stayed. (= If I had known...)

```text
If + HAD + V3, would HAVE + V3
If you HAD studied, you WOULD HAVE passed.
If we HADN'T hurried, we WOULD HAVE missed the flight.
```

## 3 classic traps

### 1. Mixing second and third conditional

- Wrong: If I had studied, I would pass. (past condition, present result = mixed, different meaning)
- Right: If I had studied, I would have passed. (both in the past)
- TR: Sonuc gecmiste ise would have + V3 sart.

### 2. Would have in the if-clause

- Wrong: If I would have known, I would have come.
- Right: If I had known, I would have come.
- TR: If'li kisma would gelmez, had gelir.

### 3. Forgetting have in the main clause

- Wrong: I would passed the exam.
- Right: I would have passed the exam.
- TR: would + have + V3, have dusmez.

## 10 example sentences

1. If I had studied harder, I would have passed. — Daha cok calsaydim geceridim.
2. If she had left earlier, she wouldn't have missed the train. — Erken ciksaydi treni kacirmazdi.
3. If we had known you were ill, we would have visited. — Hasta oldugunu bilseydik ziyaret ederdik.
4. He wouldn't have crashed if he had driven slowly. — Yavas surseydi kaza yapmazdi.
5. If they had saved money, they could have bought a house. — Para biriktirselerdi ev alabilirlerdi.
6. I would have called you, but I had lost your number. — Seni arardim ama numaranı kaybetmistim.
7. If you hadn't helped me, I would have failed. — Bana yardim etmeseydin kalirdim.
8. She might have won if she had tried harder. — Daha cok deneseydi kazanabilirdi.
9. If it hadn't rained, we would have gone hiking. — Yagmur yagmasaydi yuruyuse giderdik.
10. Had I seen you, I would have said hello. — Seni gorseydim selam verirdim.

## Quick check

1. If I ___ (know), I would have helped. → had known.
2. She ___ have missed the bus if she had run. (would/wouldn't) → wouldn't.
3. Fix: "If I would have seen him, I'd have told him." → If I had seen him...
4. If they had left earlier, they ___ (arrive) on time. → would have arrived.
5. Second or third? "If I had money now, I'd buy it." → second (present).
6. He could ___ helped if he had known. (have/has) → have.
7. Fix: "I would passed if I tried." → I would have passed if I had tried.
8. Invert: "If I had seen you..." → Had I seen you...
