# 01 — Vision: A1 to B2 in 2 Days

## Goal

One learner, one weekend, zero fluff: finish with solid B2 grammar. Not vocabulary, not speaking — **grammar only**, test-proven.

## Who

Turkish-speaking adult, false-beginner to elementary. Studies in focused sprints (25-min blocks, 8 blocks/day). All explanations in Turkish, all examples + questions in English.

## Pacing

| Day | Block | Content | Output |
|---|---|---|---|
| Day 1 AM | 4 blocks | A1 (12 topics, crash pace) | A1 gate ≥80% |
| Day 1 PM | 4 blocks | A2 (12 topics) | A2 gate ≥80% |
| Day 2 AM | 4 blocks | B1 (12 topics) | B1 gate ≥80% |
| Day 2 PM | 4 blocks | B2 (12 topics) | B2 gate ≥80% → sprint complete |

Total contact: ~12h lessons + ~4h testing. Each topic = 10-min lesson + 10-min quiz.

## Gating (the core loop)

1. **Topic quiz** after each topic (8 questions: 3 easy / 3 medium / 2 hard). Pass = ≥6/8 to mark topic done (retry allowed, new questions each retry — no-repeat).
2. **Level gate** after all topics in a level (30 mixed questions across the level's topics, difficulty-balanced). Pass = ≥80% (24/30). Fail = review deck (missed rules) + fresh 30-question retake.
3. Next level unlocks only on gate pass. No skipping.

## Success criteria

- B2 gate passed with ≥80%.
- Missed-question review deck empty (all missed rules re-answered correctly once).
- Learner can score ≥70% on a blind 50-question A1–B2 mixed final.

## Non-goals

- No vocabulary lists, no listening/speaking, no C1.
- No accounts in v1 (localStorage progress). No backend in v1 (static JSON bank).
